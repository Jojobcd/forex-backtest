# Sécurité

## Signaler une faille

Merci de ne pas ouvrir d'issue publique pour une faille de sécurité.
Utilisez le bouton **« Report a vulnerability »** de l'onglet **Security** de ce dépôt :
le signalement reste privé entre vous et le mainteneur.

## Ce que contient ce dépôt

- Aucune clé API, aucun mot de passe : les sources de données (FRED, BIS, OCDE) sont publiques et sans clé.
- Aucune donnée de trading personnelle : les sauvegardes du journal sont exclues par `.gitignore`.

## Contributions

Les contributions passent uniquement par des pull requests relues par le mainteneur.
Le code proposé par une pull request n'est jamais exécuté automatiquement.
